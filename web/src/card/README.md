# Vendored code of the TVC256k++ card

Copied from https://github.com/dikdom/tvc256kplusplus (`sources/firmware/TVC-IO`),
so that the card's file operations behave exactly like the real firmware:

- `tvc-lfs.c`, `tvc-lfs.h` – the card's littlefs file/directory operations on the
  parameter area of the IO RAM (MIT license, Vass Sándor).
  Changes: includes replaced by `card_shim.h`; file/dir handles are table indexes
  instead of raw pointers (works on 64 bit hosts too); the DSK functions are the
  firmware's again (FatFS is emulated now).
- `tvc-graphics.c` – the overlay renderer (text, bitmap, sprites, collisions), MIT.
  Changes: the REV2 board's colour tables, the PIO/DMA frame loop replaced by
  `card_gfx_vsync()` / `card_gfx_line()` at the end of the file.
- `tvc-routines.c`, `tvc-routines.h` – the built-in functions (REG_FUNCTION_EXECUTE), MIT.
  Changes: includes replaced by `card_routines_shim.h`; three bugs fixed (marked
  `Ep128web:`): functions 34 and 35 used the pointer instead of the parameters, the
  function file write ($84) copied in the wrong direction.
- `tvc-io-regs.c` – the register file part of `TVC-IO-main-sys.c` (register pointers,
  write post-processing, function dispatch), rewritten without the bus/IRQ code.
- `sprite.h`, `tvc-colors.h`, `videoton_sprites.h`, `tvc-hat.h` – data and types, MIT.
- `zx7Compress.c`, `zx7Compress.h` – zx7 decompressor by Einar Saukas (BSD-3-Clause).
- `tvc-sid.c`, `tvc-sid.h`, `tvc-sid-internal.h` – the vSID emulation (Vass Sandor, based on
  Bakisha's STM32-SID-Player and Sgw32's UltiSID). Changes: Pico include removed,
  divisions by zero give 0 as on the card's ARM core (`ARM_DIV`).
- `tvc-sound-emu.c` – the SID sample timing of `tvc-sound.c` without PWM/DMA (Ep128web).
- `tvc-fatfs.c`, `tvc-fatfs.h`, `tvc-fatfs-pendrive.*`, `tvc-fatfs-dskdrive.*` – the USB
  pendrive and DSK drive operations (FatFS), MIT. Changes: includes, portable handles.
- `fatfs/` – FatFS R0.15 as configured in the firmware (ChaN's BSD-style license, see
  `fatfs/LICENSE.txt`); `FF_USE_MKFS` is on to create the emulated pendrive.
- `diskio-emu.c` – FatFS disk I/O: the pendrive image in memory and the firmware's .dsk
  image access (from `lib/fatfs/source/diskio_usb.c`, MIT).
- `tvc-card-data.c` – font and background image (generated by `scripts/gen_card_data.py`).
- `tvc-card.h`, `card_routines_shim.h` – interface and shims (written for Ep128web).
- `littlefs/` – the littlefs library (BSD-3-Clause, see `littlefs/LICENSE.md`).
- `card_shim.h` – minimal FatFS result codes and the globals the code expects
  (written for Ep128web).

The glue to the emulated card is `../tvc256kpp_fs.cpp`.
