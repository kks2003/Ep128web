Hiányzó ROM-ok

Az emulátorhoz szükség van a gépek ROM-jaira (Enterprise: EXOS, BASIC, EXDOS…; TVC: rendszer- és bővítő ROM). Ezek szerzői jogi okokból nincsenek a csomagban.

  1. Töltsd le az ep128emu_roms-2.0.11.bin fájlt: enterpriseforever.com vagy ep128.hu
  2. Húzd ide, vagy válaszd ki:

A böngésző eltárolja (IndexedDB), legközelebb nem kell újra megadni. Egyenként is feltölthetők .rom fájlok (pl. exos21.rom, basic21.rom).

Melyik programot indítsam?

Az összes fájl a FILE: eszközre került, így a program futás közben is betöltheti a többit.

      Súgó
      • Fájl betöltése (vagy húzd a képre, akár több fájlt vagy egy .zip-et): .tap/.wav → magnó, .img/.dsk → A: lemez (TVC-n 360/720 kB-os nyers lemezkép is használható; szükség esetén EXDOS-os / VT-DOS-os gépre vált, és kilistázza), .crt → TVC cartridge (bővítő modul), .ep128s → pillanatkép, .ep128d → demó, .bin → ROM-csomag. Minden más fájl a FILE: eszközre kerül, és a program automatikusan elindul; ha több indítható program van, választhatsz.
      • TVC-játékok: nyisd meg a tvc.hu programletöltéseit, töltsd le a kiválasztott játékot, majd a „Letöltött játék indítása…” gombbal válaszd ki a .cas fájlt vagy a .zip csomagot. A böngésző biztonsági korlátozásai miatt a letöltött fájlt külön ki kell választani.
      • Utántöltős programok: tedd fel az összes fájlt egyszerre (vagy egy ZIP-ben). Az alapértelmezett eszköz a betöltés módjához igazodik (Enterprise-on :DEF_DEV_FILE / :DEF_DEV_TAPE / :DEF_DEV_DISK), így a további részek ugyanonnan töltődnek. Kazettán a többi rész magától jön a szalagról.
      • Kazetta betöltésekor a gép újraindul, és automatikusan kiadja a LOAD parancsot. Mentés kazettára: „Üres kazetta” → „● Felvétel” → BASIC-ben SAVE "név", végül „Letöltés”.
      • Enterprise-billentyűk: Esc = ESC, Backspace = ERASE, Del = DEL, Ins = INS, End vagy Pause = STOP, Home = HOLD, Alt = ALT, F1–F8 = funkciógombok, CapsLock = LOCK. A : az ' helyén, a @ a ` helyén, a ^ az = helyén van.
      • Videoton TVC: a .cas programok a FILE: eszközre kerülnek, és automatikusan elindulnak (LOAD "név" + RUN). A billentyűzet a magyar PC-kiosztást követi (QWERTZ, a 0 az 1 bal oldalán, ö ü ó a 9 után; PC Esc = ESC, a magyar PC í billentyűje = í). Magnó vagy lemez használatakor a FILE: bővítés kikapcsol (a TVC-n ez helyettesíti a magnót, és ütközik a VT-DOS-szal), .cas betöltésekor visszakapcsol. Lemezkép betöltésekor automatikusan EXT 2 + DIR.
      • Joystickok: a Joystick panelen minden bemenethez (numerikus 8/4/6/2 + 0, nyilak + jobb Ctrl, W A S D + Space, gamepad 1–4, érintős joystick) kiválasztható, melyik joystickot hajtja: TVC-n az 1. portot (= a beépített kurzorjoystick), a 2. portot vagy a GameCard 3–4. joystickját, EP-n a két külső joystickot.
      • Mobilon: a kép alatti gombokkal kapcsolható a képernyő-billentyűzet (a Shift, Ctrl és Alt egy leütésre ragad), az érintős joystick (a Joystick panel szerint, vagy kurzorbillentyűk + Space), és a szövegbeírás a telefon saját billentyűzetével. A ⛶ gombbal a kép és a vezérlők együtt kerülnek teljes képernyőre.
      • F11 = reset, Shift+F11 = hideg reset, F12 = turbó.

      Az emulációs mag az ep128emu (Varga István, GPL v2) változatlan forráskódja, WebAssemblyre fordítva.
