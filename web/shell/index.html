Hiányzó ROM-ok

Az emulátorhoz szükség van a gépek ROM-jaira (Enterprise: EXOS, BASIC, EXDOS…; TVC: rendszer- és bővítő ROM). Ezek szerzői jogi okokból nincsenek a csomagban.

  1. Töltsd le az ep128emu_roms-2.0.11.bin fájlt: enterpriseforever.com vagy ep128.hu
  2. Húzd ide, vagy válaszd ki:

A böngésző eltárolja (IndexedDB), legközelebb nem kell újra megadni. Egyenként is feltölthetők .rom fájlok (pl. exos21.rom, basic21.rom).

Súgó
  • Fájl betöltése (vagy húzd a képre): .tap/.wav → magnó, .img/.dsk → A: lemez (EXDOS kell hozzá), .ep128s → pillanatkép, .ep128d → demó, .bin → ROM-csomag, minden más (pl. .com, .bas) → a FILE: eszközre kerül és automatikusan elindul (LOAD "FILE:név").
  • Kazetta betöltésekor a gép újraindul, és automatikusan kiadja a LOAD parancsot. Mentés kazettára: „Üres kazetta” → „● Felvétel” → BASIC-ben SAVE "név", végül „Letöltés”.
  • Billentyűk: Esc = ESC, Backspace = ERASE, Del = DEL, Ins = INS, End vagy Pause = STOP, Home = HOLD, Alt = ALT, F1–F8 = funkciógombok, CapsLock = LOCK. A : az ' helyén, a @ a ` helyén, a ^ az = helyén van.
  • Videoton TVC: a .cas programok a FILE: eszközre kerülnek, és automatikusan elindulnak (LOAD "név" + RUN). A billentyűzet a magyar PC-kiosztást követi (QWERTZ, a 0 az 1 bal oldalán, ö ü ó a 9 után). Magnó használatakor a FILE: bővítés kikapcsol (a TVC-n ez helyettesíti a magnót), .cas betöltésekor visszakapcsol.
  • Joystick 1: numerikus 8/4/6/2 + 0 (tűz), gamepad, vagy a fenti kapcsoló.
  • F11 = reset, Shift+F11 = hideg reset, F12 = turbó.

Az emulációs mag az ep128emu (Varga István, GPL v2) változatlan forráskódja, WebAssemblyre fordítva.
